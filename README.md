
## Project Overview
An end-to-end data analytics project focused on understanding customer purchasing patterns, product preferences, and shopping behavior using Python, PostgreSQL, and Power BI.

## Dataset
- **Records:** 3,900
- **Columns:** 18
- **Missing Values:** 37 in the Review Rating column

## Tools & Technologies
- **Python:** Data cleaning, EDA, and feature engineering
- **Pandas:** Data manipulation and analysis
- **PostgreSQL:** SQL-based data analysis
- **Power BI:** Interactive dashboard and visualization

## Project Workflow
1. **Data Loading & Exploration:** Loaded the dataset and explored its structure and summary statistics.
2. **Data Cleaning:** Handled missing review ratings, standardized column names, and checked data consistency.
3. **Feature Engineering:** Created an age-group feature and a purchase-frequency-related feature.
4. **SQL Analysis:** Used PostgreSQL to analyze customer shopping behavior and purchasing patterns.
5. **Dashboard Development:** Built a Power BI dashboard to visualize customer behavior and shopping trends.

## How to Run
1. Clone this repository.
2. Install Python and the required libraries.
3. Run the Python notebook or script for data cleaning and analysis.
4. Execute the SQL queries in PostgreSQL.
5. Open the Power BI `.pbix` file in Power BI Desktop.
